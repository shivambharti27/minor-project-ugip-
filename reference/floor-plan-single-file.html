Floor Plan Generator — Architectural Demo

Auto-plans an Indian-style compact home from just the plot size and entrance direction: room count and sizes are decided by plot area, and every room opens directly into the Hall (no corridors). Switch to the 3D tab to see the same layout as an extruded model — drag to rotate, scroll to zoom.

How this works: Plot area decides the rooms (e.g. ~600 sq.ft → 2 BHK, ~1200 sq.ft → 3 BHK + dining). A seeded search tries thousands of room arrangements and keeps the one with the best sizes, door access to the Hall and daylight. The same geometry drives the 2D plan and the 3D model. The gold marker is the main entrance.
